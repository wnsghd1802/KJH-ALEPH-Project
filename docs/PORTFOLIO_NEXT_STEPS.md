# SE 포트폴리오 증빙·후속 작업 (2026-10-29)

본 문서는 공개 포트폴리오에 없는 경력을 만들어 넣지 않고, 실제 수행한 작업에 대한 근거를 추가하기 위한 작업 목록입니다.

## 우선순위 A: 기존 실습의 증빙 보강
1. **LogAnalyzer**: 실제 로그 조회 결과 화면 한 장. 서버 IP·계정·개인정보 마스킹.
2. **Linux 웹/DB/DNS**: 각 개별 실습에 대한 설정 화면 또는 결과. 웹 응답, DB 서비스 상태, DNS 질의 결과를 가능하면 각각 구분해 기록.
3. **Snort IPS**: 동일 요청에 대한 변경 전후 응답과 DROP 로그의 시각 연결. 실습망 범위만 공개.
4. **현장 경력**: 회사·고객사명을 노출하지 않고 담당 역할과 선배가 맡은 역할을 구분한 작업 경험.
5. **공개 문의 수단**: 지원 연락을 받을 이메일 또는 연락 폼. 계정·비공개 정보 공개 금지.

## 우선순위 B: 다음에 실제 수행할 학습 기록
6. Apache 서비스 장애와 복구 실습: 증상 → 로그·포트·서비스 상태 확인 → 조치 → HTTP 응답 검증.
7. DNS 구성 오류 실습: 테스트 환경에서 오류 발생 → 점검 → 수정 → 질의 결과.
8. MariaDB 접속 실패 실습: 원인을 계정·권한·연결로 분리하고 재검증.
9. Wazuh Agent 1514/TCP 연결 문제 후속: 관리 서버 측 수신 설정 확인, 실제 연결 성공 시에만 완료 표시.
10. 실제 서비스 변경/롤백 체크리스트: VM에서 실행하여 검증한 뒤 작성.

## 주의
- 상용 Linux SE 운영 경력 없음. 실무 네트워크 경험과 교육 실습은 반드시 구분.
- 확인하지 않은 성능 수치, 가용성, 복구 시간, 무중단 운영 성과 사용 금지.
- 회사명·고객사명·내부 IP·계정·토큰·개인정보 비공개.
- 자료를 첨부하는 경우 원본에서 비밀정보를 제거한 뒤 공개.
